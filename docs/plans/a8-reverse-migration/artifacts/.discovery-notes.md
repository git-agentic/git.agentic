## Tech stack

- **Rust workspace** pinned to 1.95 via `rust-toolchain.toml`. Workspace crates: `agentic-core`, `agentic-memory`, `agentic-proto`, `agentic-cli`, `agenticd`.
- **Async runtime:** tokio multi-thread runtime; `agenticd` uses a `LocalSet` for the per-connection request loop.
- **Database driver:** `sqlx` with the Postgres feature. `PostgresAdapter` holds a `PgPool`.
- **Test runner:** `cargo test`. Integration tests for `agenticd`/`agentic-memory` snapshot+restore must hit a real Postgres+pgvector — mocking is forbidden by CLAUDE.md.
- **CI:** GitHub Actions; runs `cargo check`, `cargo test`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --check`. SDK has separate Python lanes (`ruff`, `mypy --strict`, `pytest`).
- **Demo harness:** `examples/langgraph-rollback/docker-compose.yml` (Postgres+pgvector on `54322`).

## ADRs the plan must respect

- **ADR-0001** (`docs/adr/0001-architecture-foundations.md`) — Postgres+pgvector only for MVP memory. No second backend lands in this PR.
- **ADR-0002** (`docs/adr/0002-substrate-and-supercommit.md`) — Decision 3: mandatory 2PC staging order (blobs → hashes → Commit blob → Git push → ref update). Decision 5: bounded rollback for destructive migrations (snapshot restore). Decision 6: SDK trades in Commit objects only; no storage-layer leaks. **The bounded-rollback path is the v1.1 scope referenced by `accept_data_loss`'s docstring (`migrate.rs:21-22`).**
- **ADR-0005** (Proposed, `docs/adr/0005-sessionstore-amendment-to-adr-0004.md`) — SessionStore amendment. Touches `MemoryAdapter` trait; A9 (audit-deferred) waits on this. **Not relevant to A8.**
- **ADR-0010 / 0011** (Proposed, `docs/adr/0010-*`, `0011-*`) — wire-protocol error model + ObjectStore async-trait shape. Not relevant to A8 (no wire change, no ObjectStore change).
- No ADR mandates a particular shape for `MemoryAdapter::restore`'s schema_version handling — that is open.

## Coding standards (from CLAUDE.md)

- **Rust:** `rustfmt` defaults, `clippy -D warnings`. No `unwrap()` in non-test code without `// SAFETY:` or `// INVARIANT:` comment. `thiserror` in library crates, `anyhow` in binaries. `agentic-memory` is a library → `thiserror::Error` via its `crate::Error`. `agenticd` is a binary → `anyhow::Result` is the prevailing style.
- **Don't mock Postgres for snapshot/restore tests.** Snapshot/restore code paths must exercise a real Postgres+pgvector in CI integration tests. The demo's docker-compose is the conventional test target.
- **Don't reorder the 2PC staging in commit code.** A8 does NOT touch commit code — only rollback. Stays safe.
- **One conceptual change per PR.** B8+B9+B10 are bundled because the audit ships them as one recommendation (§A8); the unified justification is in the audit doc.
- **HEREDOC commit messages, merge commits (not squash), `gh pr merge --merge --delete-branch`.**
